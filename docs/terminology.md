# Терминология

Единые термины для всех трёх языков сайта. Источник, с которым их нужно
сверить: Экологический кодекс Республики Казахстан от 2 января 2021 года
№ 400-VI (действующая редакция; история редакций — zakon.uchet.kz,
документ K2100000400). **Статус: на сверке.** Определения из статьи кодекса
об основных понятиях при подготовке этого списка открыть не удалось, поэтому
ни один термин не помечен как сверенный.

| Понятие | Русский (на сайте) | Қазақша (на сайте) | English (on site) | Где используется | Статус |

| состояние среды | состояние окружающей среды | қоршаған ортаның жай-күйі | state of the environment | миссия, бриф, профиль ассистента | на сверке |

добавляется сюда.
