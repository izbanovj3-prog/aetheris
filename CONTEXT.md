## Что сделано

**E1 · Репозиторий** — `.gitattributes` (LF), `.env.example` без значений;
CRLF в индексе не было (проблема была только в локальной Windows-копии).

**A1 · База данных** — миграция №7 `supabase/privacy-hardening.sql` и откат
`supabase/rollback/privacy-hardening.down.sql`:
- координаты сообщений хранятся с точностью ~1 км; координаты отметки на
  событии используются для расстояния и не сохраняются;
- `anon_id` не читается посетителями; запись — только колонки сообщения
  (статус, голоса, автор, «передано», «ответ» недоступны);
- закрыта дыра: раньше любой мог удалить все записи на любое событие;
- удаление своего сообщения (кроме уже переданных — их убирает команда);
- лимит по сети 30/час, 100/сутки по хэшу IP с суточной солью, хэши 24 ч;
- действия от имени устройства — только с новыми v2-идентификаторами
  (старые были публичными).
Клиент работает и до, и после миграции. `test:security` перенацелен на
отдельный тестовый проект и отказывается работать с боевым URL.

**A2/A3 · Приватность** — согласие перед отправкой; честные тексты: фото не
загружается, EXIF/GPS удаляются; кнопка удаления; черновики `/privacy` и
`/terms` на трёх языках с плашкой «на юридической вычитке».

**A4/A5 · Безопасность** — CSP, HSTS, nosniff, X-Frame-Options,
Referrer-Policy, COOP, Permissions-Policy (`vercel.json`); e2e проверяет, что
CSP ничего не ломает. Next 16.4.4 и `npm audit fix` без смены мажоров.

**B · Честность данных** — убраны «real-time», «сеть датчиков», «станции»,
«люди подтверждают», «Aetheris Systems»; новые OG-картинки на три языка;

«Live» — только у реально полученных значений; каждый ответ ассистента с

`tests/honesty.test.ts`.

**C · Языки** — сообщество, форма, события, статусы, Eco-Points в
`lib/communityText.ts` (en/ru/kk); `/ru/community`, `/kk/community`;

**D · Качество** — axe-контраст и отсутствие горизонтального скролла на

трёх языках; правильный `lang` до загрузки JS; SEO-тесты; работа без JS.

## Решения и почему

| Решение | Почему |
| --- | --- |
| Фото остаётся на устройстве (решение владельца) | Модерации нет; публичные загрузки фото — главный риск злоупотреблений и персональных данных |
| Публичные координаты ~1 км (решение владельца), точная точка не хранится нигде | Минимизация персональных данных; в базе нечего утечь |
| Лимит по хэшу IP с суточной солью (решение владельца) | Лимит по `anon_id` обходится сменой id; сырой IP не хранится |
| `anon_id` → v2, старые id не дают прав | Старые были публичными, значит не доказывают владельца |
| Сначала деплой фронтенда, потом миграция | Новый клиент работает с обеими схемами; старый ломается после миграции |
| `script-src 'unsafe-inline'` в CSP | Статический export встраивает inline-скрипты гидратации, nonce невозможен; сторонних скриптов нет, `unsafe-eval` нет |
| `geolocation=(self)` на весь сайт | Клиентская навигация сохраняет политику первой страницы; ограничение по пути сломало бы форму |
| HSTS без `preload` | Попадание в preload-список трудно отменить — решение владельца |
| Редирект www → apex не в `vercel.json` | Мог бы зациклиться с настройкой домена в Vercel; проверяется после деплоя |
| `maplibre-gl` 5 и `vitest` 3 не обновлены | Фикс только в новых мажорах (запрещено); уязвимость MapLibre недостижима с нашим вводом, vitest — только dev |
| Глобус не грузится на экранах < 1024px, при reduced-motion, Save-Data, программном WebGL | Это декорация и самая тяжёлая загрузка; на телефоне блокировала поток на 151 с в Lighthouse |
| Казахский не помечен в интерфейсе | Требование задачи; список для носителя — `docs/kk-review.md` |
| Термины помечены «на сверке» | Текст Экологического кодекса из песочницы открыть не удалось |
| Проверка превью/прода — через GitHub Actions | Песочница не видит supabase.co, vercel.app, aetherisearth.live, open-meteo.com |
